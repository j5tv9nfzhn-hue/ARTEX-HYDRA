## 二、现有前端审计结果（全部为只读 grep/读取实测）

技术栈：Next.js 16 + React 19 + Tailwind v4（CSS-first，无 tailwind.config）+ shadcn。桌面端 = Wails WebView2 渲染同一份前端（`IS_DESKTOP` 仅门控免登录/侧栏账户区），系统原生标题栏（无 Frameless），窗口/托盘/图标上轮已按规范处理。

### P0 功能缺陷（3 项）

1. **死工具类一整串**：`message-scroller.tsx:45`、`function/assets/page.tsx:874`、`assets-tab.tsx:210` 使用的 `scrollbar-thin`、`scrollbar-gutter-stable`、`scrollbar-track/thumb-transparent`、`scroll-fade-b` 在全 web 目录**零定义**（v4 无内置、无插件、globals.css 无 `@utility`）。后果：滚动条样式与渐隐全部无效。
2. **IME 伴生 Enter 幽灵键可穿透**：`lib/chat-send-mode.ts:66-71`（shouldSubmitOnKey）、`mention-textarea.tsx:147`（仅 `composing.current` 判断）、`side-question-workspace.tsx:162`（仅 isComposing）。部分输入法引擎下确认选词的 Enter 在 `isComposing` 复位后到达（keyCode=13），会把选词误发成消息。
3. **流式上翻无「回到底部」**：`chat/page.tsx:842` 只解构 `pin/reset`，`atBottom` 未接 UI；全站无回底按钮。

### P1 视觉规范批量偏差（2 项，机械性大 diff）

4. **<12px 字号 209 处 / 34 文件**：`text-[9px]`（transcript.tsx:55、chat:503）、`text-[10px]`（dashboard 72 处最多、sessions-tab 12 处）、`text-[11px]`（skills 页 16 处等）。全部收敛到 `text-xs`（=12px），层级改用字重/灰阶表达。
5. **中点「·」分隔符**：前端 99 行 + `zh.json` 116 行。**注意耦合**：`server/engine.go:1305` 用 `"%s · #%d"` 生成 agent_name，`sessions-tab.tsx:1450` 用 `/·\s*#(\d+)$/` 正则反解析——必须前后端同改（含 `conversations.go` 合并触发标题、`notify_api.go` 测试消息名、`branch_gate.go` 文案）。纯展示拼接改 flex gap；协议串改 `work#N-#42` 并同步正则 + 兼容旧数据。

### P2 风格收敛（需你拍板，视觉风险大）

6. **0.5px hairline 边框**：shadcn 全站 1px border，全局改细需真机验证（WebView2 DPI 表现），建议 token 级开关灰度。
7. **同心圆角**（R_inner=R_outer−padding）：Card(12px) 内嵌 Badge/Button(6px) + p-6(24px) 按公式应为直角——抽查主要页面后小幅修。
8. **border-l-2 判定为功能性保留**：blockquote 引用条、树形缩进线、会话激活指示条（chat:1219、sessions-tab:528）属状态语义非装饰彩条，**不动**。
9. **冗余文案**：本项目卡片描述是「为什么」中文注解（仓库惯例），只清明显占位 hint，不做大规模删减。
