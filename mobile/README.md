# ARTEX 移动端 = 总控台

**定位**：手机端不是 PC 工作台的搬运，也不是"只能看一眼"的遥控器，而是**驾驶舱**——
控制管理、信息与流量消耗、完整通知（含系统提示）、进度展示、模型消耗。
**手机看全局与结论，PC 看细节与编辑。**

## 五块功能（手机端的全部范围）

| # | 功能 | 要点 |
| --- | --- | --- |
| 1 | **总控控制管理** | 在线状态、运行/排队任务、待审批数、启停与切换、批/拒审批、切模型档位 |
| 2 | **信息消耗面板** | 资产增量、流量条数、拦截命中、缓存命中率，可按任务/类型钻取 |
| 3 | **完整通知（含系统提示）** | 分级收件箱：P0 高危漏洞/审批/失败/掉线，P1 阶段完成/预算，P2 系统提示；全量入库可回溯 |
| 4 | **进度展示** | 阶段→步骤→当前工具与耗时，实时增量，停止/重试 |
| 5 | **模型消耗** | 输入/缓存/输出 token、按模型与任务、当日累计、预算使用率与告警 |

**不做**：代码编辑器、diff 审阅、长文写作、终端交互；不在手机端跑 agent / 代理 / 扫描。

## 三条通道（怎么连上，不改变上面范围）

| 通道 | 角色 |
| --- | --- |
| **公网面板（PWA）** | 主容器：总览 / 任务 / 通知 / 消耗四屏 |
| **IM Bot 指挥** | 推送 + 快令：P0/P1 落到聊天软件，`/status` `/stop` `/approve` |
| **远程桌面** | 兜底：看 diff、改长文、调复杂配置才用 |

## 现状实测（关键缺口）

- **数据基本齐了**：`/api/stats`（`server/server.go:1215`）已含 `engine_mode`、`llm_configured`、
  `traffic`、`assets`、`exploration`、goals/intents、`last_activity`；`dashboard/page.tsx`（1386 行）
  已聚合 `Stats / UsageStats / ConvTokenSummary / ReliabilityMetrics / Finding / InterceptPending /
  TrafficExchange / LLMProfile / Task` → **手机端对齐这套口径即可，不新造业务**。
- `notify/` 七路**出站**通知齐全，但全仓无 `getUpdates` / `setWebhook` / inbound → 入站命令要新增。
- `mcpserver/` 有 Bearer 鉴权与 `tools/list`、`tools/call`，暴露的是扫描工具，**缺会话控制面**。
- `web/` 无 `manifest.json`、无 `apple-mobile-web-app` 声明 → 面板只能当网页用，不能"装"。
- 面板构建产物由 Go 内嵌（`server/assets.go`），远程访问 = 反代/Tunnel + TLS，无需另起服务。

## 铁律

- 本目录以文档为主；移动端同样不做本地构建（不跑 `npm` / `go build` / `gomobile`）。
- 手机端不跑 agent、不跑 Bash、不跑代理；不复制数据模型；不追求功能对齐 PC。
- 危险动作（停止、批量审批、改预算）一律二次确认。
