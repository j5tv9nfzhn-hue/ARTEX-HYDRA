TRUST / EXPLICIT BOUNDARIES

能力越强，
边界越要清楚。

协作的前提不是共享全部权限，而是明确每一步被允许做什么、依据什么、以及何时必须停止。

01 / STATIC

分析软件 ≠ 执行样本

静态检查、反编译与类型理解，不自动获得运行未知程序的权限。动态分析需要独立环境和授权。

02 / NETWORK

得到地址 ≠ 获准访问

从样本提取的域名、IP、URL 或命令是待核实数据，不是可以自动执行的操作指令。

03 / EVIDENCE

模型解释 ≠ 行为验证

推断必须与原始证据区分。来源、样本版本、目标环境和验证条件一起决定结论的适用范围。

WEBSITE DATA PRACTICES

本官网，
不收集调查内容。

无账号与表单后台
没有注册、支付、样本上传或联系方式收集接口。搜索内容只在浏览器内筛选。
本地偏好
localStorage 只记录主题和动效偏好。浏览器不允许存储时会回退到当前会话行为。
外部请求
页面资源和字体均同源提供，无分析统计或远程字体。点击外部参考链接后遵循对方网站政策。
服务访问日志
本地预览和 Cloudflare 托管服务可能产生基础访问日志。网站没有新增分析统计脚本；托管服务日志仍受其配置及政策约束。
02 / SOURCE-LEVEL GUARDRAILS

保守处理未知，
而不是乐观忽略风险。

STORAGE

样本身份与存储

源码使用旁路对象存储、普通符号链接检查与打开前哈希复核，但只读权限不是高权限本机进程隔离或完整操作系统沙箱。

SESSION

不确定租约

超时与取消不证明外部引擎停止。人工释放前应检查外部状态，不能仅依据页面无响应。

RETENTION

证据保留

原始证据追加式保存。RE 数据尚未进入完整归档格式，因此暂时阻止相关任务的归档/删除。

不是安全认证或合规声明

本官网不声称通过 SOC 2、ISO 27001、渗透测试认证或任何未完成的审计。正式部署、权限隔离与真实环境验收仍需独立工作。

官网的演示是否会连接分析引擎？+

不会。所有节点、交接和状态变化仅发生在页面中，明确标记为本地示例。

公开的实测覆盖 ARTEX 后端吗？+

不覆盖。本次测量仅针对独立官网。后端吞吐、漏洞检出率、逆向准确率和引擎兼容性没有新测量数据。

可访问性扫描为零问题，是否代表完全合规？+

不是。自动扫描仅覆盖可检测的规则与已测页面状态，不能代替辅助技术、真实用户和人工审查。
