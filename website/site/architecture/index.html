01 / DOMAIN MODEL

任务领域，与项目范围分开。

领域模型 / 概念
project                 // 规划层
  ├─ task: web_security
  ├─ task: software_re
  └─ handoff: artifact@version

analysis_domain         // 已有任务字段
  = web_security | software_re

不急着引入第三种 hybrid 任务。

混合工作不是第三种专业，而是多个专业任务的协作。现有 analysis_domain 保留为执行任务的领域，避免一次运行混入全部工具和权限。

项目 ID、依赖 DAG 和交付物契约尚未接入当前后端。官网架构图是实现方向，不是数据库现状图。

02 / FAILURE IS A FIRST-CLASS STATE

不确定状态，
不能被一个绿色圆点掩盖。

SESSION

ready ≠ 分析完成

ready 只代表连接与打开操作成功，不代表所有分析结束或全部能力可用。

CANCELLATION

超时 ≠ 引擎已停止

取消、重启和连接失败保守保留租约，必须确认外部分析停止后才能释放。

LIFECYCLE

归档 ≠ 丢弃扩展对象

现有归档格式未包含 RE 数据，因此含样本的任务暂时阻止归档和删除。
