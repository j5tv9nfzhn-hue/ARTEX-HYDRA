01 / ORIENTATION

这是什么网站？

这是 ARTEX 的独立、多页面产品官网，不是原有控制台的替代品。所有演示均在浏览器本地运行；没有接入账号、支付、分析引擎或生产任务。

如果希望了解功能，请先阅读双领域平台与开发记录。如果希望操作真实任务，需要另行配置并授权运行 ARTEX 主项目，官网不会提供不存在的登录入口。

02 / DOMAIN MODEL

领域、任务与联合项目

web_security 与 software_re 是执行任务的领域。网络任务处理授权目标和资产，逆向任务处理样本、函数和会话。未来统一项目层组织这些任务的目标、依赖和交付关系。

项目层仍处于设计阶段；本网站的编排组件是交互示例，不会启动任何子任务。

03 / PROVIDER CONTRACT

接入 REA / Ghidra / IDA 之前

  1. 确认引擎、插件版本、许可证和目标平台适配条件。
  2. 停止旧的直连分析客户端，再登记受管 Provider。
  3. 读取真实工具目录与 schema，不照抄未经验证的参数。
  4. 审核只包含静态操作的映射。open 模式必须明确 open 与 close。
  5. attach 模式必须核对现有分析数据库的真实样本 SHA-256。
  6. 独立验证实时能力、打开、查询、关闭和不确定租约清理。

当前源码仅允许本地 stdio 打开共享路径样本。目录发现不等于引擎就绪；详细边界见软件逆向。

04 / WEBSITE ONLY

本官网的运行与预览

站点是无构建的静态多页面源码：直接双击 site/index.html 即可打开，不需要本地服务；预览服务使用 Node.js 20+ 标准库，无需安装依赖。开发依赖只用于测试与测量工具。

TERMINAL / WEBSITE
npm run preview

默认预览端口 4173，监听 0.0.0.0。源码即部署内容，位于 site/；页面、样式与脚本直接编辑生效，不存在构建步骤。

TERMINAL / WEBSITE
npm ci
npm run test
npm run measure

浏览器测试与测量前先安装依赖与 Playwright Chromium；测量时保持预览服务运行。measure 重新生成报告并同步到 site/reports/；实测页摘要是静态文本，更新需手工同步 site/benchmarks/index.html。这些操作不构建或测试 ARTEX 主项目。

05 / CLOUDFLARE READINESS

独立发布，保持边界

本次核查确认远程电脑已安装 Wrangler 4.131.2；采用超时保护的 whoami 查询成功返回，CLI 已登录。账号详情不公开；已获授权创建独立官网 Pages 项目，不覆盖已有项目。ARTEX 主项目中未发现 wrangler 配置文件。

本官网使用独立 wrangler.toml，发布目录为 site/，不包含账户 ID 或 Token。经授权发布到独立 Pages 项目 artex-official-website.pages.dev。未绑定自定义域名、修改 DNS 或覆盖原有服务。

目前使用 Cloudflare Pages 默认域名。后续绑定自定义域名仍需单独确认；不要将本地测量当作 Cloudflare 全球边缘网络表现。

06 / DESIGN NOTES

参考方法，不复制作品

视觉采用编辑式大标题、工程线框、低饱和表面与酸柠色强调；v3 升级引入层叠大气层（网格、颗粒、径向光晕）、渐变描边卡片、幽灵字标注与轨道式信息图。深浅两套语义 token 覆盖页面、图表、工作台、搜索和文档；滚动显影、跑马灯与指针聚光是渐进增强，动效支持暂停及系统减少动态效果。
