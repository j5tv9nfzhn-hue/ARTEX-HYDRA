## 文档约定

- **语言**：统一简体中文。项目不再提供其他语言界面与文档。
- **编号**：文件名前缀数字仅用于排序，不代表阅读顺序或重要程度。
- **可验证性**：文档中的数字（技能数、预设数、接口名）必须来自源码实测，不沿用旧文档的措辞。改动代码时同步更新。
- **历史记录**：`10-` 开头的是时点性审计记录，保留原貌，不随代码演进更新。
