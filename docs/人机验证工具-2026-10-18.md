# 人机验证专业工具：源码交付记录

日期：2026-10-18。状态：源码新增/接入，待编译与运行验证。不得将格式检查或研究资料视为测试通过。

## 需求纠偏

存在 Cloudflare/CDN 或验证码 widget 不等于不能自动完成。ARTEX 继续由 AI 使用现有工具选择协议、浏览器等降级，不新增验证码人工交互、浏览器安装或发行流程。不把自动处理写成“全部交给人工”，也不把任意指纹/遥测伪造宣传为已具备能力。

## 本次源码

1. `human_verification(mode=inspect)`：对已有响应做分诊，无网络请求；涵盖 Cloudflare 明确信号、AWS 动作/状态组合、常见 widget、未知拒绝、限流及疑似 ClickFix。
2. `human_verification(mode=solve_pow)`：标准库实现明确的 ALTCHA salt+number SHA-256/SHA-512 公开 PoW，免费本地计算，输出标准 Base64 payload；不验证服务端 HMAC、不代替业务确认。
3. `http_request(http_version=auto|1.1|2)`：选择标准协议；省略保留原行为，2 仅支持 HTTPS；独立缓存 transport clone，不修改已使用的共享 transport。
4. `http_request` 返回增加 `human_verification` 结构；HTTP 200 的明确挑战、动态正文或截断正文可纳入原有同键 3-Strike。
5. Worker/pentest 默认工具目录、技能嵌入、技能关键词路由与默认可见性接入；既有用户可见性关闭配置通过 insert-if-absent 保留，不重刷历史技能迁移标志。
6. Worker 内置提示补充专用工具用法。未擅自重置现有数据库中的自定义提示词或工具绑定。

## 预算与返回

- 默认最多 100000 次、2000ms；单次硬上限 1000000 次、5000ms；支持 context 取消。
- 校验摘要长度、算法、公开 expiry、salt/signature 长度与 maxNumber。
- 同一工具实例按公开挑战身份缓存结果；更改本地预算、摘要大小写或 maxNumber 不重算同一 proof。
- 每工具实例最多 64 个不同挑战；超过后返回 `strategy_exhausted`。等待计算槽位可取消。
- `proof_computed` 不等于过验证；`business_accepted=false`。业务提交仍走现有授权工作流，并独立核查实际结果。

## 非目标与局限

首期没有增加第三方 Go 依赖，也没有安装付费或云端打码服务。未提供通用视觉/音频解码、Argon2/Sentinel、所有 PoW 协议、TLS 指纹伪装、风控遥测注入或生产站突破保证。

原有止损只覆盖单次运行内 http_request/http_fuzz 的同键后续调用；不覆盖跨 Worker、跨轮、Bash/MCP、一次批量 Fuzz 内的所有请求。PoW 缓存属于单工具实例，不宣称全任务防火墙或彻底杜绝所有循环。

inspect 是保守启发式分析。疑似 ClickFix 返回提醒，不因网页内容而执行命令。普通 403/429 或一段 widget 标记不是厂商/攻击结论。
